# Breathavia Pro

Carte de séance respiratoire Buteyko / Oxygen Advantage.
Fonctionne hors-ligne comme une app installable (PWA).

## Déploiement sur GitHub Pages

### 1. Créer le dépôt

- Va sur [github.com/new](https://github.com/new)
- Nom du dépôt : `breathavia-session-map`
- Visibilité : **Private** (recommandé)
- Ne coche PAS "Add a README file"
- Clique **Create repository**

### 2. Uploader les fichiers

- Sur la page du dépôt vide, clique **"uploading an existing file"**
- Glisse-dépose **tous les fichiers et le dossier `icons/`**
- Clique **Commit changes**

### 3. Activer GitHub Pages

- Va dans **Settings** > **Pages**
- Source : **Deploy from a branch**
- Branch : **main**, dossier **/ (root)**
- Clique **Save**
- Attends 1-2 minutes

### 4. Accéder à l'app

```
https://TON-USERNAME.github.io/breathavia-session-map/
```

### 5. Installer comme app

**iPad** : Safari > Partager > "Sur l'écran d'accueil"
**Mac** : Chrome > barre d'adresse > icône d'installation
**Windows** : Chrome/Edge > trois points > "Installer Breathavia"

## Notes

- Les données restent locales (localStorage), rien n'est envoyé au serveur
- Exporte en Word/Excel régulièrement comme sauvegarde
- Fonctionne hors-ligne après la première visite
